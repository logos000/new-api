分组说明

创建令牌时可选择分组,不同分组对接不同上游池,模型清单与倍率可能不同。令牌不指定分组时按账户默认分组路由。

分组面向说明
默认分组推荐常规聚合池,覆盖绝大多数模型,不确定就选它
vip 分组特定用户需管理员开通,倍率更优
Claude Code 专用可选专供 Claude Code 客户端(Anthropic 原生格式 /v1/messages),其他工具调用会报错
Codex 专用可选专供 Codex CLI(/v1/responses),其他客户端调用会报错
Gemini 分组可选原生 Gemini 与 OpenAI 格式均可用,含最新 Gemini 系列
选错分组的典型报错是 403 无权访问 xxx 分组 或上游参数错误 —— 换回默认分组即可。名称中带「自用」字样的分组为站方内部订阅通道,不对外提供支持,请勿选择。

文本对话(Chat Completions)

标准 OpenAI Chat 格式,支持 glm、deepseek、claude、gemini 等系列。

curl
curl https://api.infinmag.com/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-3.5-flash",
    "messages": [{"role": "user", "content": "你好,介绍一下你自己"}]
  }'
python
from openai import OpenAI

client = OpenAI(api_key="sk-xxx", base_url="https://api.infinmag.com/v1")

resp = client.chat.completions.create(
    model="gemini-3.5-flash",
    messages=[{"role": "user", "content": "你好"}]
)
print(resp.choices[0].message.content)
node
import OpenAI from "openai";

const client = new OpenAI({ apiKey: "sk-xxx", baseURL: "https://api.infinmag.com/v1" });

const resp = await client.chat.completions.create({
  model: "gemini-3.5-flash",
  messages: [{ role: "user", content: "你好" }],
});
console.log(resp.choices[0].message.content);

流式输出

请求体加 "stream": true(SDK 中 stream=True / stream: true),SSE 格式与 OpenAI 完全一致,按 delta.content 增量拼接:

curl
curl https://api.infinmag.com/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-3.5-flash",
    "stream": true,
    "messages": [{"role": "user", "content": "写一首关于春天的诗"}]
  }'

Claude 原生格式(/v1/messages)

已在用 Anthropic SDK / Claude Code 的用户无需改造,改 base_url 直连。

python
from anthropic import Anthropic

client = Anthropic(api_key="sk-xxx", base_url="https://api.infinmag.com")

msg = client.messages.create(
    model="claude-sonnet-4-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "你好"}]
)
print(msg.content[0].text)
也可直接 POST https://api.infinmag.com/v1/messages,请求/响应体与 Anthropic 官方格式一致,请求头用 x-api-key 或标准 Bearer 均可。

视频生成

支持 MiniMax H3、豆包 Seedance 2.5,采用异步任务模式。计费 = 单价 × 视频秒数,提交任务时预扣,失败自动退回。

模型说明单价(美元/秒)
minimax-h3MiniMax H3,文生视频$0.16
minimax-h3-maxMiniMax H3 Max$0.10
doubao-seedance-2-5-260628字节 Seedance 2.5,多模态参考(图/视频/音频)、原生音效$0.31(720p)
STEP 1 · 提交任务

POST /v1/videos
记下返回的 id;也支持统一格式 POST /v1/video/generations
STEP 2 · 轮询状态

GET /v1/videos/{id}
建议每 15 秒一次:queued → in_progress → completed / failed
STEP 3 · 下载视频

GET /v1/videos/{id}/content
下载链接 24 小时内有效,请及时转存
submit
curl -X POST https://api.infinmag.com/v1/videos \
  -H "Authorization: Bearer sk-xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-5-260628",
    "prompt": "一只橘猫坐在钢琴前弹奏爵士乐,暖色调,电影感镜头",
    "duration": 5,
    "resolution": "720p"
  }'

Seedance 专属参数

参数类型说明
promptstring必填,1–2000 字符
durationint时长秒数,整数 4~15;填 -1 由模型自动决定(按实际秒数计费)
resolutionstring"480p" / "720p"(默认)
ratiostring画面比例:"adaptive"(默认)/ "16:9" / "9:16" / "1:1" / "4:3" / "3:4"
generate_audiobool是否生成声音,默认 true
watermarkbool是否加水印,默认 false
extra_body.contentarray多模态参考:传参考图/视频/音频做图生视频、风格迁移
图生视频
{
  "model": "doubao-seedance-2-5-260628",
  "prompt": "让画面中的猫咪动起来",
  "duration": 5,
  "extra_body": {
    "content": [
      {"role": "reference_image", "content": [{"type": "image_url", "image_url": {"url": "https://你的图片地址.jpg"}}]}
    ]
  }
}
minimax-h3 系列建议先只传 model + prompt 最小参数调用;如需指定时长等参数,以报错提示为准。

语音合成(TTS)

Gemini 系列 TTS,文字转自然语音,支持语气风格控制与多角色对话。

curl
curl https://api.infinmag.com/v1/audio/speech \
  -H "Authorization: Bearer sk-xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-3.8-flash-tts",
    "input": "欢迎使用 InfinMag API!",
    "voice": "Kore",
    "response_format": "wav"
  }' \
  -o speech.wav

Python 用法与 OpenAI SDK 一致:client.audio.speech.create(model=..., voice="Kore", input="...")

推荐音色

Kore坚定
Puck欢快
Zephyr明亮
Charon沉稳
Aoede轻快
Leda年轻
Fenrir热烈
Enceladus含蓄
⚠️ 请使用以上 Gemini 音色名,不要使用 alloy、echo 等 OpenAI 音色名,会报错。

高级用法:语气与多角色(instructions)

json
{
  "model": "gemini-3.8-flash-tts",
  "input": "Speaker1: 今天天气真好!Speaker2: 是啊,出去玩吧!",
  "voice": "Kore",
  "instructions": "用轻松愉快的语气;Speaker1 声音专业,Speaker2 声音活泼"
}
限制说明
输出格式仅 wav / pcm(不支持 mp3)
语速不支持 speed 参数(请写进 instructions)
长度单次最长 4096 字符
计费音频输出约 $0.012/分钟(文本输入费用极低可忽略),按实际时长计费

余额与用量查询(API)

无需登录后台,用 API Key 直接查(与 OpenAI 计费接口兼容)。

总额度

错误码

出错时统一返回 OpenAI 风格 JSON。

json
{
  "error": {
    "message": "无效的令牌",
    "type": "new_api_error",
    "code": "invalid_token"
  }
}
HTTP 状态常见原因处理
401Key 错误 / 令牌已过期或被禁用检查 Authorization: Bearer sk-xxx,或到令牌页重建
403无权访问该模型(分组限制)联系管理员开通
404模型名错误或未上架以 GET /v1/models 返回为准
429触发限流稍后重试;频繁出现可联系提额
5xx上游临时故障重试;持续出现请联系管理员
-insufficient quota余额不足,请充值
❓

常见问题

TTS 报 No matching speaker voice found
音色名错误。Gemini TTS 请用 Kore / Puck 等音色,见上方推荐音色表。
TTS 返回的是 json 头?
正常现象,响应体实为 WAV 音频,按二进制保存即可(-o speech.wav)。
视频任务一直 queued
排队中属正常;超过 30 分钟未变请带任务 id 联系管理员。
视频下载链接失效
下载链接 24 小时有效,过期需重新生成。
想要流式但收到整段
请求体加 "stream": true。
SDK 报证书错误
请使用 https://api.infinmag.com 官方域名,勿用备用 IP。

English Quick Start

bash
# Chat
curl https://api.infinmag.com/v1/chat/completions -H "Authorization: Bearer sk-xxx" \
  -H "Content-Type: application/json" \
  -d '{"model":"gemini-3.5-flash","messages":[{"role":"user","content":"Hello!"}]}'

# Video (async: submit -> poll GET /v1/videos/{id} -> download GET /v1/videos/{id}/content)
curl -X POST https://api.infinmag.com/v1/videos -H "Authorization: Bearer sk-xxx" \
  -H "Content-Type: application/json" \
  -d '{"model":"doubao-seedance-2-5-260628","prompt":"a cat playing jazz piano","duration":5,"resolution":"720p"}'

# TTS (Gemini voices only: Kore, Puck, Zephyr, ...; wav/pcm output)
curl https://api.infinmag.com/v1/audio/speech -H "Authorization: Bearer sk-xxx" \
  -H "Content-Type: application/json" \
  -d '{"model":"gemini-3.8-flash-tts","input":"Hello from InfinMag!","voice":"Kore"}' -o out.wav

# Balance
curl https://api.infinmag.com/v1/dashboard/billing/subscription -H "Authorization: Bearer sk-xxx"
